# 🗺️ Carte Moulins

Un site web interactif pour visualiser et gérer des points d'intérêt (moulins) sur une carte OpenStreetMap.

## ✨ Fonctionnalités

- 🗺️ Carte interactive basée sur OpenStreetMap (Leaflet.js)
- 📍 Visualisation des points (waypoints) d'un fichier GPX
- ➕ Ajouter de nouveaux points en cliquant sur la carte
- ✏️ Modifier les points existants
- 🗑️ Supprimer les points
- 📤 Exporter les points en fichier GPX
- 📥 Importer des fichiers GPX
- 🎨 Personnaliser la couleur de chaque point
- 📱 Design responsive (desktop & mobile)

## 📖 Comment utiliser

### Ajouter un point
1. Clique n'importe où sur la carte → Les coordonnées se remplissent automatiquement
2. Remplis le nom et la description
3. Choisis une couleur
4. Clique sur "➕ Ajouter"

### Modifier un point
1. Clique sur un point dans la liste ou sur la carte
2. Modifie les informations dans le formulaire
3. Clique sur "💾 Modifier"

### Supprimer un point
1. Sélectionne le point
2. Clique sur "🗑️ Supprimer"

### Importer/Exporter GPX
- **Importer**: Clique sur "📥 Importer GPX" et sélectionne un fichier .gpx
- **Exporter**: Clique sur "📤 Exporter GPX" pour télécharger un fichier
